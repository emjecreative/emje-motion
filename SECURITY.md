# Security Policy

## Supported Versions

Only the latest release is supported with security updates.
Check the [Releases page](https://github.com/emjecreative/emje-motion/releases/latest)
and update to the newest `emje-motion-x.y.z.zip`.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No — please update first |

## Reporting a Vulnerability

Please **do not open a public issue** for security vulnerabilities.
Use [private vulnerability reporting](https://github.com/emjecreative/emje-motion/security/advisories/new)
so the issue can be fixed before it is disclosed.

What to include:

- Plugin version and WordPress / Elementor / PHP versions used
- Steps to reproduce (or proof of concept)
- Expected vs actual behavior and the impact you see

## Response Expectations

- Acknowledgement within 7 days.
- A fix or mitigation is released as soon as one is verified,
  with credit to the reporter unless anonymity is requested.
- Please allow time for the fix to ship before any public disclosure
  (coordinated disclosure).
